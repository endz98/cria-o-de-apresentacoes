# Briefing de apresentação

O briefing vem junto com o prompt. Use esta lista só para conferir se falta algo importante e pergunte apenas o essencial:

- **Objetivo:** vender, aprovar, informar, inspirar?
- **Público:** cliente, parceiro, equipe, diretoria?
- **Quantidade de slides:** aproximada.
- **Conteúdo obrigatório:** tópicos, vinhos, preços, datas, números.
- **Arquivo Figma:** link onde criar.
- **Fotos específicas:** alguma imagem que já precisa entrar?

Se algo não for informado, assuma o mais razoável, siga e diga o que assumiu.
